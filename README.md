# Reveal in iTerm2

VS Code 탐색기나 편집기에서 폴더를 iTerm2로 바로 열 수 있는 확장입니다.

## 기능

- **탐색기 컨텍스트 메뉴**: 폴더 우클릭 → "Reveal in iTerm2"
- **편집기 탭 컨텍스트 메뉴**: 파일 탭 우클릭 → "Reveal in iTerm2"
- **명령 팔레트**:
  - `Reveal in iTerm2` - 현재 파일의 폴더 열기
  - `Reveal Workspace Root in iTerm2` - 워크스페이스 루트 열기

## 요구사항

- macOS
- [iTerm2](https://iterm2.com/) 설치 필요

## 설치

1. `.vsix` 파일 다운로드
2. 파일 더블클릭하여 VS Code에서 설치

또는 VS Code에서:
1. `Cmd+Shift+P` → "Extensions: Install from VSIX..."
2. `.vsix` 파일 선택

## 사용법

### 탐색기에서
폴더를 우클릭하고 "Reveal in iTerm2" 선택

### 편집기 탭에서
파일 탭을 우클릭하고 "Reveal in iTerm2" 선택

### 명령 팔레트에서
`Cmd+Shift+P`를 누르고:
- `Reveal in iTerm2` - 현재 열린 파일의 폴더를 iTerm2로 열기
- `Reveal Workspace Root in iTerm2` - 워크스페이스 루트를 iTerm2로 열기

# Reveal in iTerm2 (English)

A VS Code extension to open folders in iTerm2 directly from the explorer or editor.

## Features

- **Explorer Context Menu**: Right-click folder → "Reveal in iTerm2"
- **Editor Tab Context Menu**: Right-click file tab → "Reveal in iTerm2"
- **Command Palette**:
  - `Reveal in iTerm2` - Open current file's folder
  - `Reveal Workspace Root in iTerm2` - Open workspace root

## Requirements

- macOS
- [iTerm2](https://iterm2.com/) installed

## Installation

1. Download the `.vsix` file
2. Double-click to install in VS Code

Or in VS Code:
1. `Cmd+Shift+P` → "Extensions: Install from VSIX..."
2. Select the `.vsix` file

## Usage

### From Explorer
Right-click a folder and select "Reveal in iTerm2"

### From Editor Tab
Right-click a file tab and select "Reveal in iTerm2"

### From Command Palette
Press `Cmd+Shift+P` and:
- `Reveal in iTerm2` - Open the current file's folder in iTerm2
- `Reveal Workspace Root in iTerm2` - Open the workspace root in iTerm2
